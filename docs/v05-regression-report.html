5. What Shipped — Architecture Context

v0.5 extends the SDI engine from a 6-entity model (D2 + D14 AutonomyPolicy) to the canonical 7-entity model by promoting CollaborationPattern to first-class status (D22). Every work entity now carries a non-null produced_via_pattern_id (D23) — direct is the explicit solo-flow marker, not an escape hatch — and the four pattern kinds (workflow, graph, swarm, agents-as-tools) each ship with a mechanical shape gate enforced at the pending → active lifecycle transition (D26, D27). Graph consensus is sybil-blocked by counting distinct (AgentSpec.name, Stance) tuples instead of bare names.

Pattern recursion forms a DAG via parent_pattern_id bounded by AutonomyPolicy.pattern_depth_cap with explicit cycle detection (D24), and autonomy itself becomes pattern-scoped: the strictest of (plan-mode, pattern-mode) wins (D25, defaults workflow=L5 / graph=L5 / swarm=L4 / agents-as-tools=L4 / direct=L3-forced). On top of that, reversibility is first-class on Decision via reversal_plan + blast_radius_score + append-only reversal_of consensus rows (D28), and multi-session resource claims live in a daemon-centric ledger (claimed_resources_json + claim_status) queried by PreToolUse hooks to block cross-session path overlaps (D29).
